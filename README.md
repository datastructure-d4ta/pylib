Hello! I am making a library for python! Updates will be frequent until far in the future when I no longer exist. Now, everything is in the library but I'll give you the commands.
stuff.bigmult() with no parameters (because none are accepted) will ask the user what 2 numbers they would like to do and then put those 2 numbers through a mathematical equation.
stuff.fprint(text) and similar commands with print in it will simply print it but make it look good. Look into the library for more information.
stuff.asklist(text) will ask the text that you put into it and then when you say "stop" or "end" with any uppercase or lowercase letters and then return everything that you just said.
stuff.rvar(variable) will return any variable, text, int, float, or anything else you put into it.
stuff.mupr(content, number) will either print the text you put into it `number` times or multiply the 2 numbers you put into it and return that.
stuff.nonbig(number1, number2) will do what bigmult() does but instead of the user putting in the numbers, the developer puts in the numbers.
stuff.get(website, apikey=None) will make an API get request with a predetermined User-Agent and if you assign an API key, it will put in that API key.
